# Ashesh Chakraborty | SDET Portfolio

This is a static personal portfolio for a Senior SDET / QA Automation Engineer, designed to be hosted on GitHub Pages.

## Files included
- index.html
- styles.css
- script.js

## Local preview
Open the project in a browser directly, or run a small local web server from the project folder:

python -m http.server 8000

Then open:

http://localhost:8000

## GitHub Pages deployment
1. Push this project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to Settings > Pages.
4. Choose the main branch or the correct folder for publishing.
5. Save the settings and wait for deployment.
6. Use the generated URL to view your site.

## Customize content
Replace the placeholder content in index.html with your own:
- name
- bio
- skills
- projects
- experience
- contact information

## Notes
This starter is intentionally lightweight and easy to extend as your portfolio grows.
